# Task Management Mobile App

Aplikasi manajemen tugas berbasis Flutter dengan fitur task penting, progress harian, chart aktivitas mingguan, realtime search, dan SQLite local database.

## Features

- Tambah tugas penting & biasa
- Progress harian
- Grafik aktivitas mingguan
- Realtime search
- SQLite local database
- SharedPreferences

## Tech Stack

- Flutter
- Dart
- SQLite
- SharedPreferences




## Installation

```bash
flutter pub get
flutter run
